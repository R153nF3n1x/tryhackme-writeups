# Hacker Holidays

Write-ups from the TryHackMe Hacker Holidays event series, set across the fictional Byte Lotus resort.

This progressive CTF connected a shared cast of characters across a wide range of disciplines: OSINT pivoting from images and overheard conversations, AI prompt injection and persona impersonation, exposed Git repositories, AWS Cognito and DynamoDB abuse, covert C2 channel detection in PCAP traffic, game binary reverse engineering, and chained web vulnerabilities escalating from credential exposure to full remote code execution. Boot2root challenges covered Java deserialization, YAML injection, Node.js debug port exploitation, and Linux disk group privilege escalation.
