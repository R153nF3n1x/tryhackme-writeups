# Love at First Breach 2026

Write-ups from the Love at First Breach 2026 Valentine's Day CTF event on TryHackMe.

This themed event covered a range of web exploitation techniques across a suite of intentionally vulnerable applications: unpatched framework CVEs, JWT algorithm confusion attacks, unrestricted file upload leading to RCE, stored XSS against automated headless browser reviewers, IDOR via sequential identifiers, and MD5 collision attacks against hash-based matching systems.
