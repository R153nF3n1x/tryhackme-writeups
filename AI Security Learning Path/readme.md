# AI Security Learning Path

Write-ups from TryHackMe rooms focused on AI and machine learning security.

This path covers prompt injection, indirect extraction attacks, RAG pipeline data boundary violations, supply chain attacks on ML models, LLM threat modelling using the OWASP LLM Top 10, AI-assisted DFIR investigation, and OT/ICS security fundamentals.

These rooms sit at the intersection of traditional security analysis and emerging AI attack surfaces, reflecting the growing need for SOC analysts to understand how AI systems can be exploited, misused, or weaponised.
