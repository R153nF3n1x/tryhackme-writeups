# SOC Level 1 Learning Path

Write-ups from the TryHackMe SOC Level 1 learning path.

This path covers the core skills required for a Tier 1 SOC analyst role: phishing email analysis and header forensics, OSINT investigation across social media and open sources, SIEM investigation using Splunk SPL, network traffic analysis with Wireshark, malware sandbox analysis using ANYRUN and VirusTotal, Linux command line proficiency, and web application vulnerability fundamentals including IDOR and hash manipulation.

The write-ups follow a consistent format designed to reflect real SOC investigation workflows, with each room including a What I Would Flag in a Real SOC section mapping findings to practical detection and response actions.
